# Code of Conduct · Quy tắc ứng xử · 行为准则

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1: be kind, be respectful, no harassment. Enforcement: report unacceptable
behavior privately to the maintainers via a GitHub Security Advisory or a
private message; reports stay confidential.

Dự án tuân thủ [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1: tử tế, tôn trọng, không quấy rối. Báo cáo hành vi xấu riêng tư cho
maintainer qua GitHub Security Advisory hoặc tin nhắn riêng; mọi báo cáo được
giữ bí mật.

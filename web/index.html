BƯỚC 1Kết nối board

Cắm board bằng cổng USB-UART, rồi bấm kết nối và chọn đúng cổng trong hộp thoại.

Không kết nối được thì: giữ nút BOOT, nhấn nhả nút RESET, thả BOOT ra, rồi bấm Kết nối lại. Nếu vẫn lỗi, đổi cáp USB hoặc hạ tốc độ nạp xuống 115200.

BƯỚC 2Chọn firmware

Gói có sẵn được kiểm tra SHA-256 trước khi nạp. Pico-fido tự build thì thêm file gộp ở mục bên dưới.

Đang tải danh sách firmware có sẵn...
Bạn đang mở file trực tiếp nên trình duyệt chặn tải firmware có sẵn. Hãy chạy scripts/web_flasher.ps1 để mở qua localhost, hoặc dùng file tự chọn.

BƯỚC 4Serial Monitor

Xem log hwtest: chờ dòng ESP32-S3 Security Key: hwtest, nhấn nút BOOT để thử.

Log serial
Luồng chuẩn từ đầu tới cuối
  1. Kết nối board, đọc chip để chắc đúng ESP32-S3.
  2. Nạp hwtest bản OTG, web tự mở Monitor sau khi xong.
  3. Kiểm tra log chip, nhấn BOOT, xem LED xanh lá chuyển xanh dương.
  4. Đạt hết mới nạp pico-fido (file gộp .bin ở 0x0) theo hướng dẫn firmware.
Chạy hoàn toàn trên máy bạn bằng esptool-js và WebSerial. Không gửi dữ liệu đi đâu.

# Security Policy · Chính sách bảo mật · 安全政策

## English

- Supported: the latest `main` branch. Security fixes land on `main` first.
- Report privately: use GitHub Security Advisories
  ("Report a vulnerability" on the Security tab). Do NOT open public issues
  for vulnerabilities.
- Scope: `tools/`, `firmware/`, `web/`, `scripts/`, `config/`, this repo's
  docs. Out of scope: upstream pico-fido / ESP-IDF / Arduino core / pip
  libraries (report to their maintainers, then tell us so we can pin or
  work around).
- Response: acknowledgement within 3 days; fix target 30 days for
  High/Critical, 90 days for Medium/Low.
- Safe harbor: good-faith research that avoids data destruction, service
  disruption and social engineering is welcome. Never test against other
  people's keys or accounts.

## Tiếng Việt

- Bản được hỗ trợ: nhánh `main` mới nhất. Bản vá bảo mật lên `main` trước.
- Báo cáo riêng tư: dùng GitHub Security Advisories (nút "Report a
  vulnerability" ở thẻ Security). KHÔNG mở issue công khai cho lỗ hổng.
- Phạm vi: `tools/`, `firmware/`, `web/`, `scripts/`, `config/` và tài liệu
  của repo. Ngoài phạm vi: pico-fido / ESP-IDF / Arduino core / thư viện pip
  (báo cho upstream, rồi báo lại để repo ghim hoặc né).
- Phản hồi: xác nhận trong 3 ngày; mục tiêu vá 30 ngày cho High/Critical,
  90 ngày cho Medium/Low.
- Nghiên cứu thiện chí (không phá dữ liệu, không tấn công dịch vụ hay con
  người) được chào đón. Không bao giờ thử nghiệm trên key/tài khoản người khác.

## 简体中文

- 支持版本：最新的 `main` 分支，安全修复优先合入 `main`。
- 私下报告：请使用 GitHub Security Advisories（Security 选项卡中的
  "Report a vulnerability"）。请勿公开提交漏洞 issue。
- 范围：`tools/`、`firmware/`、`web/`、`scripts/`、`config/` 及本仓库文档。
  上游项目（pico-fido / ESP-IDF / Arduino core / pip 库）请报告给上游，
  并通知我们以便固定版本或规避。
- 响应：3 天内确认；High/Critical 目标 30 天修复，Medium/Low 目标 90 天。
- 欢迎善意研究（不破坏数据、不攻击服务和人员）。绝不要在他人的
  密钥或账户上做测试。
